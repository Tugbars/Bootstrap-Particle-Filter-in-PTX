01 — The Problem

Genealogical collapse kills long windows

After enough resampling events, most θ-particles descend from a handful of ancestors. The cloud looks wide but explores nothing. With 1,024 outer particles, collapse occurs after ~3,000–4,000 ticks — and doubling to 2,048 doesn't help. The bottleneck is tree depth, not tree width.

02 — The Architecture

Amnesiac windows, Kalman memory

Each SMC² window reinitializes from prior — full particle diversity, healthy ESS, genuine posterior exploration bounded to 3K ticks. The Kalman filter accumulates cross-window information without particles, without resampling, without genealogical trees. Just a mean and covariance, updated forever.

03 — Why It Works

Bounded depletion, unbounded memory

Particle depletion is exponential — it's a race against time that particles always lose. The Kalman filter sidesteps this entirely. It has no particles, no resampling, no genealogical tree. Information capacity is bounded only by numerical precision.

The interaction is the whole story. Kalman does nothing for a traveling cloud — it already has memory, Kalman just adds lag. But Kalman is transformative for amnesiac clouds — it's the only thing providing cross-window continuity. Traveling + Kalman is the worst mode: smoothing a degenerating cloud's noise with delay.

05 — Bugs That Masked the Design

Two one-line fixes, months of confusion

Previous tests showed the Kalman architecture underperforming. The design was correct — two bugs in the test harness made it look broken.

Bug 1: Observation Transform

SMC²/RBPF uses OCSN parameterization: y = log(r²)

Test fed raw returns (y ≈ 0.1) instead of log-squared (y ≈ −4.6). SMC² shifted mu_base by ~3 units to compensate.

✗ smc2_update_batch(smc2, raw_returns, N)
✓ smc2_update_batch(smc2, log_returns_sq, N)

Bug 2: DGP Model Mismatch

RBPF uses z-dependent θ(z) mean-reversion, not constant ρ

DGP used h = ρ·h + (1-ρ)·μ(z) but RBPF uses h = (1-θ(z))·h + θ(z)·μ(z). At high z, RBPF mean-reverts 5× faster — mu_base shifted ~1.5 units.

✗ h = mu_z + rho * (h - mu_z) + ...
✓ h = phi*h + theta_z*mu_z + ...

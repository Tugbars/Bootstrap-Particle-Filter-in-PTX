§1

The Model

The system estimates a two-factor stochastic volatility model with regime-dependent dynamics. A latent stress process z̃t modulates both the level and the volatility-of-volatility of log-volatility ht through nonlinear curves. Returns are conditionally Gaussian given ht.

State: stress dynamics z̃_t = ρ · z̃_{t-1} + σ_z · ε_z,t ε_z ~ N(0, 1)
State: log-volatility dynamics h_t = μ(z_t) + θ_speed · (h_{t-1} − μ(z_{t-1})) + σ_h(z_t) · ε_h,t ε_h ~ N(0, 1)
Observation y_t = exp(h_t / 2) · ε_y,t ε_y ~ N(0, 1)
Stress mapping z_t = 1.5 · (1 + tanh(z̃_t)) z ∈ [0, 3]

The stress z̃t is an AR(1) process in unbounded space. The tanh mapping compresses it to [0, 3] before it enters the curves. This ensures the curves are bounded and monotone — μ(z) rises from a floor to a ceiling as stress increases, and σh(z) does the same.

Curve Definitions

Both curves share the same saturating-exponential form, parameterized by a base (floor), scale (ceiling − floor), and rate (curvature):

Mean curve: level of log-volatility μ(z) = μ_base + μ_scale · (1 − exp(−μ_rate · z))
Vol-of-vol curve: h-innovation amplitude σ_h(z) = σ_base + σ_scale · (1 − exp(−σ_rate · z))

At z = 0 (calm), μ(0) = μbase and σh(0) = σbase — the floor parameters control all dynamics. As stress rises, the curves saturate at μbase + μscale and σbase + σscale. The rate parameters control how quickly the ceiling is reached.

Reparameterization

The model has two independent volatility channels: σz (stress innovation) and σbase (h-innovation floor). In the natural parameterization, the likelihood constrains only their total energy σz² + σbase² — creating a ridge the sampler cannot escape efficiently. The reparameterization rotates this:

Polar reparameterization σ_total = √(σ_z² + σ_base²) total vol-of-vol energy r = σ_z / σ_total channel split ratio ∈ (0, 1) Inverse: σ_z = r · σ_total σ_base = √(1 − r²) · σ_total

The 8 learned parameters are therefore: (ρ, σtotal, r, μbase, μscale, μrate, σscale, σrate). The 3 derived quantities (σz, σbase, θspeed) are computed from the learned parameters before being pushed to the BPF. θspeed is derived from ρ and σz to match the effective mean-reversion timescale of the discretized system.

§2

Initialization

At cold start (t = 0), no data has been observed and no windows have completed. The system initializes in a conservative state that produces reasonable filtering immediately, then self-corrects as the Kalman accumulates window posteriors.

Priors

Each SMC² window initializes θ-particles from independent priors. These are chosen to be weakly informative — centered on typical equity-index values with enough spread to cover the plausible range. Parameters are sampled in constrained space and transformed internally.

Parameter Prior Support Rationale
ρ Beta(8, 2) (0, 1) Peaked near 0.8 — stress is persistent
σtotal Half-N(0, 0.5²) (0, ∞) Positive, moderate total vol-of-vol
r Beta(2, 2) (0, 1) Symmetric — no prior preference for channel split
μbase N(−10, 2²) (−∞, ∞) Typical log-vol for equity indices: exp(−10) ≈ 0.005
μscale Half-N(0, 3²) (0, ∞) Ceiling is above base; wide to cover crises
μrate Exp(1) (0, ∞) Curvature — uninformative, learned from stressed data
σscale Half-N(0, 1²) (0, ∞) Vol-of-vol ceiling increase under stress
σrate Exp(1) (0, ∞) Curvature — uninformative

Kalman Cold Start

The Kalman tracker initializes with:

Kalman initial state x₀ = prior mean of each parameter P₀ = diag(prior variance) large — low confidence Q = diag(drift rates) per-param, from slow/fast classification

With P₀ large, the Kalman gain after the first window is near 1.0 — the first SMC² posterior essentially overwrites the prior. This is correct: before any data, the Kalman should trust the first measurement completely.

BPF Before First Window

The BPF begins filtering immediately at t = 0 using the prior means as initial parameters. These values are approximate but functional — the BPF produces usable h-estimates even with imprecise parameters, because particle filtering is robust to moderate parameter misspecification (particles adjust their spread to accommodate the mismatch).

After the first SMC² window completes (t = 3000 at stride 1500, covering ticks 0–2999), the Kalman updates and pushes corrected parameters to the BPF. From this point forward, the system is in its normal operating mode. Convergence to accurate parameters typically requires 3–5 windows (4500–7500 ticks), depending on signal richness.

Phased Learning at Start

The system always starts in Phase 1 (4 free parameters: ρ, σtotal, r, μbase). The curve parameters (scale, rate) are locked to their prior means. This is correct because early data is likely calm (no stress observed yet), and attempting to learn curve ceilings from flat data wastes particles. As the market enters its first stressed period and zmax rises, the ratchet promotes to Phase 2 and then Phase 3 automatically.

The Eight Parameters

The stochastic volatility model is parameterized by eight quantities that control the dynamics of latent log-volatility ht and its coupling to the stress factor z̃t. Parameters are grouped by their characteristic timescale — how quickly they drift in practice.

Parameter Symbol Role Drift
rho ρ AR(1) persistence of z̃ — controls stress memory medium
sigma_total σtotal Total vol-of-vol: √(σz² + σbase²) medium
r_split r Channel split: σz = r · σtotal medium
mu_base μbase Baseline log-vol level — tracks market regime fast
mu_scale μscale μ(z) curve ceiling: how much stress lifts log-vol slow
mu_rate μrate μ(z) curve curvature: how fast the ceiling is reached slow
sigma_scale σscale σh(z) curve ceiling: stress amplifies h-innovation noise slow
sigma_rate σrate σh(z) curve curvature slow

The (σtotal, r) Reparameterization

The natural parameterization (σz, σbase) creates a severe identification ridge — the likelihood constrains σz² + σbase² (total energy) but not the individual components. MCMC samplers and particle filters waste iterations sliding along this ridge without improving estimates.

The reparameterization σtotal = √(σz² + σbase²) and r = σz / σtotal decorrelates the two: σtotal is pinned by total volatility magnitude (identifiable from any data), while r controls the split between the observable and latent channels. This collapses the ridge into an axis-aligned posterior, dramatically improving mixing and convergence.

Curve evaluation f(z) = base + scale · (1 − exp(−rate · z)) μ(z) = μ_base + μ_scale · (1 − exp(−μ_rate · z)) σ_h(z) = σ_base + σ_scale · (1 − exp(−σ_rate · z)) where z = 1.5 · (1 + tanh(z̃)) ∈ [0, 3]

Key Observations

The BPF never blocks — it continues per-tick filtering throughout the SMC² window computation. Parameter updates are atomic snapshots: the BPF reads the latest ParamSnapshot at its next tick, with no synchronization overhead. The SMC² window runs on a background CUDA stream, overlapping with BPF kernel launches on the default stream.

The Phased controller operates at the window boundary — it receives z-statistics accumulated during the previous 1500 ticks, checks phase transition triggers, and updates the fixed_mask before SMC² initializes. This means the mask change takes effect within the same window that triggered it.

§8

SMC² — The Sensor

Sequential Monte Carlo squared (SMC²) is a particle filter over parameters. Each of the 1024 θ-particles proposes a complete parameter vector. For each θ, an inner RBPF evaluates how well that parameter explains the observed data — producing a marginal likelihood that determines the particle's weight.

Amnesiac Windows
Why reinitialize from prior every window

A traveling particle cloud — carried forward across windows — degenerates after ~3000 ticks regardless of particle count. Weight collapse concentrates mass on a few particles, and no amount of rejuvenation recovers diversity in 8 dimensions.

The amnesiac design reinitializes all θ-particles from the prior each window. Every window is an independent measurement of the parameter posterior. This eliminates degeneration entirely, at the cost of discarding inter-window memory. The Kalman tracker recovers that memory by fusing the independent posteriors.

Tested: AMNESIA+KALMAN achieves 0.57 RMSE vs 0.97 for traveling cloud — a 41% improvement.

§9

RBPF — Rao-Blackwellized Likelihood

For each θ-particle, 512 inner particles track the latent state z̃t by particle filtering, while the log-volatility ht is integrated out analytically via a Kalman filter conditional on z̃. This Rao-Blackwellization dramatically reduces the variance of the marginal likelihood estimate — essential for SMC² to discriminate between θ-particles.

OCSN Approximation

The observation model yt = exp(ht/2) · εt is non-Gaussian in h. The standard trick: transform to log y² = h + log ε², where log ε² follows a log-χ²(1) distribution. This is approximated by a 10-component Gaussian mixture (Kim, Shephard & Chib, 1998), enabling closed-form Kalman updates for h conditioned on each mixture component.

The RBPF's job is not to produce the best h-estimate — that's the production BPF's role. Its job is to produce low-variance marginal likelihoods so SMC² can learn good parameters. The slight approximation from OCSN is acceptable because it's the teacher, not the student.

RBPF likelihood (per θ-particle) p(y₁:T | θ) = ∏ₜ p(y_t | y₁:t₋₁, θ) ≈ ∏ₜ [ (1/N) Σᵢ Σⱼ π_j · N(log y²_t ; μ_h,i + m_j, σ²_h,i + v_j) ] where i indexes z̃-particles, j indexes OCSN mixture components, and (μ_h,i, σ²_h,i) is the Kalman posterior for h given z̃_i
§10

CPMMH — Rejuvenation

When the outer ESS drops below threshold (typically 50%), θ-particles are resampled and then rejuvenated via Correlated Pseudo-Marginal Metropolis-Hastings. Each rejuvenation step proposes a perturbation θ′ near the current θ, replays the window using correlated noise (ρCPMMH ≈ 0.95), and accepts or rejects via the PMMH ratio.

Noise correlation is critical: without it, the proposed trajectory would be independent of the current one, making acceptance rates near zero in high dimensions. The correlated construction ensures the proposed likelihood tracks the current one closely, achieving 20–40% acceptance in 8D.

Proposals use an adaptive Cholesky factorization of the empirical θ-covariance, scaled by 2.38²/d as per optimal random-walk Metropolis theory. The Cholesky is updated after each resampling event.

§11

Kalman Stitching

Each amnesiac SMC² window produces an independent measurement (θ̂k, Σk). The Kalman filter treats these as observations of slowly-drifting true parameters. With H = I and F = I, the Kalman equations reduce to:

Kalman predict + update Predict: P̄ = P + Q Innovate: S = P̄ + Σ_k Gain: K = P̄ · S⁻¹ Update: x ← x + K · (θ̂_k − x) P ← (I − K) · P̄

The key insight: the Kalman automatically downweights uninformative windows. When SMC² reports wide Σk (e.g. during calm periods with no signal), S grows large, K shrinks, and the update barely moves x. When Σk is tight (crisis, rich signal), the update is aggressive. No tuning required — the information content of each window is encoded in its covariance.

Process Noise Q

Q encodes expected parameter drift per window. Fast parameters (μbase: Q = 10⁻³) get large Q, allowing rapid tracking. Slow curve parameters (μscale, σrate: Q = 10⁻⁷) get tiny Q, accumulating information over many windows. This dual-timescale design matches the economic reality: market level shifts weekly, curve shapes shift over months.

§12

Phased Learning

Not all eight parameters are identifiable from all data. During calm periods (z ≈ 0), only the floor parameters (ρ, σtotal, r, μbase) are identifiable — curve ceilings and rates require high-stress data to pin down. Trying to learn all 8 from calm data wastes particles exploring the unidentifiable ridge.

Phased learning uses a ratchet mechanism that progressively unlocks parameters as the observed z-range widens. The ratchet never locks back — once unlocked, parameters stay free. This is correct for the amnesiac architecture because each window starts fresh, and the Kalman handles calm-period uncertainty automatically (wide Σ → low gain).

Design Decisions

Several architectural alternatives were implemented and tested before arriving at the current design. Each was evaluated on multi-regime synthetic data spanning calm, crisis, and recovery periods.

Adopted
Amnesiac + Kalman
0.57 RMSE vs 0.97 traveling cloud (−41%). Each window is an independent sensor. Kalman fuses them optimally. No particle degeneration.
Rejected
Traveling Cloud
Weight collapse after ~3K ticks. Rejuvenation cannot recover diversity in 8D. Degenerates regardless of particle count.
Adopted
Ratchet (One-Way)
0.60 RMSE, 10/12 segment wins. Stays at Phase 3 continuously. Calm-period cost is just wider posteriors, which Kalman absorbs.
Rejected
Bidirectional Valve
+23% RMSE vs ratchet. Re-unlock latency after calm periods (6 windows minimum). Solves a problem that doesn't exist in amnesiac architecture.
Adopted
RBPF Inside SMC²
Rao-Blackwellization gives low-variance likelihoods. Essential for discriminating 1024 θ-particles. BPF inner was tested — signal too noisy.
Rejected
Warm-Start from Kalman
+25% RMSE. Creates feedback trap — particles confirm Kalman's early bias. Cold init preserves independence that makes fusion robust.
